# 手机能力验证版

入口：终端长按，选择「DroidUse 手机能力」。

本轮实现 Shizuku 连接监听、授权申请、拒绝授权提示、运行身份查询；可启动应用列表和启动应用通过 Android 原生 API 实现。暂未实现 Shizuku UserService、特权脚本、无障碍或 AI。

## 验证步骤

1. 未启动 Shizuku 时打开页面，显示未连接，不应崩溃。
2. 通过无线调试启动 Shizuku，返回页面刷新。
3. 申请授权，先拒绝；身份查询应提示先授权。
4. 在 Shizuku 中允许后返回，身份查询预期为 UID 2000。
5. 停止 Shizuku，页面应显示未连接，后续查询不能误报成功。
6. 查询可启动应用，点击一个应用，检查是否出现目标界面。

列表只在手机显示，不上传。启动返回仅代表启动请求已发送，不等同于业务任务成功。

## 安装限制

当前 CI 使用临时 debug 签名，可能无法覆盖此前安装。不要直接卸载已有环境；需要迁移或稳定签名方案后再处理安装冲突。
